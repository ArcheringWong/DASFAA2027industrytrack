# D0 实验协议（2026-11-13，实验前）

1. 先核查 dlt #4523/#4525、Airbyte #84400/#82705、Airbyte CAT 与状态化测试已有能力；不得把 Issue 当作本地实测。
2. 真实 dlt 优先使用 1.31.0（报告受影响）与含 #4525 修复的版本，隔离 Python 环境和内存 DuckDB；固定两轮、两页、`id` 唯一、游标 `ts=2`、`row_order='desc'`、闭区间。记录版本、页请求、目标行、检查点；做升序、无同游标等必要对照。旧版报错或环境不兼容时区分环境故障与逻辑行为。
3. Airbyte 若缺 Snowflake 账号，只做公开源码/PR/测试审查；若运行独立精度模型，标记 `MODEL_ONLY`，不能声称连接器复现。
4. 强基线为明确源身份标准答案的两轮边界测试、已有码库回归测试、成熟状态机/属性测试、参考模型差分。只有真实实现中出现它们不能合理覆盖的新增失效类，才进行生成器开发。
5. 合成数据、本地运行、无企业连接。每个包环境、命令和最多分钟级运行设超时；不无限随机测试，不提交上游。所有文件限定在 `D_checkpoint_safety`，不清理其他项目。
