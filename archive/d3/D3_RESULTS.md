# D3 实验结果

日期：2026-11-14；本地合成源、真实 dlt→内存 DuckDB；Python 3.11.4、dlt 1.31.0/1.32.0、DuckDB 1.5.6、PyArrow 26.0.0。事前性质与协议见 `D3_METAMORPHIC_SPEC.md`、`D3_EXPERIMENT_PROTOCOL.md`。这里仅统计 D3 新运行；D0–D2 历史证据另列基线。

## 核心同一性质的真实结果

`metamorphic.py` 接受合法基础历史与中性前缀配方，不按 Issue 编号分支。`confirmed_boundary` 从 prior 中最大已确认游标选择旧身份；`excluded_null` 自动分配新 ID、生成 typed 空游标批次。合法性验证分别计算原始和变形的预期集合，然后运行两个独立真实 pipeline。

| dlt / 变形 | 独立预期最终 ID | 原始目标 / 请求批次 | 变形目标 / 请求批次 | 结论 |
|---|---|---|---|---|
| 1.31.0 / 已确认边界前缀 | `{1,2}` | `{1,2}` / `[1]` | `{1}` / `[1]`，新 `id2` 所在批未请求 | `TRUE_VIOLATION` |
| 1.32.0 / 已确认边界前缀 | `{1,2}` | `{1,2}` / `[1]` | `{1,2}` / `[1,2]` | `PASS` |
| 1.32.0 / 排除空游标前缀 | `{3,4}` | `{3,4}` / `[1]` | 空 / `[1]`，有效批未请求 | `TRUE_VIOLATION` |

两个变形均未改变合格记录的身份、游标、可见性或产品设置；前缀中性理由由独立源模型及配置验证。边界前缀在 prior 中已确认，闭区间与主键去重允许它重读；Arrow 前缀按 `exclude` 过滤。真实 `pipeline.run()` 均未抛异常。第一类证据与已修复 [#4523](https://github.com/dlt-hub/dlt/issues/4523) 对应；第二类与仍无正式修复版本对照的 [#4284](https://github.com/dlt-hub/dlt/issues/4284) 对应。变形后单独比较目标不同**不是**判故障的依据；各边均先与自身独立预期比对。

手工成对预检先于自动实现，见 `D3_CROSS_MECHANISM_RESULTS.md`；它同样得到上述方向。自动案例的空游标前缀 ID 为程序从基础历史派生的 `5,6`，与预检手工 `1,2` 不同但均不新增合格 ID。自动结果不是把手工样例 JSON 原样回放。

## 正常、非法和不确定对照

`cases.json` 有 20 个预设案例，按版本展开 28 个版本案例。合法案例共 16 对、32 个独立真实场景、52 次 `pipeline.run()`；执行耗时的各对计时和约 25 秒（不含 Python 启动和环境安装）。非法案例 12 个在产品调用前拒绝。汇总：

| 状态 | 数量 | 典型证据 |
|---|---:|---|
| `PASS` | 13 | 无前缀；相同游标同页；正常边界重读；空游标位于有效记录之后或同一批内；去掉升序声明；无剩余合格 ID；`merge` 目标的身份集合完整 |
| `TRUE_VIOLATION` | 2 | 上表两个旧/受影响机制 |
| `INVALID_TRANSFORMATION` | 12 | 未确认新前缀、空值 `include`、不稳定同游标排序、原记录被删、改变上界/写入语义、源覆盖不明、输入格式不支持；`base` 和 `transformed` 均为 `null`，没有连接器调用 |
| `INCONCLUSIVE` | 1 | 1.31.0 基线本身已有旧边界遗漏；不能把变形差异归因于新前缀 |
| `EXECUTION_ERROR` | 0 | 分类分支已实现，本次未观察到执行异常 |

分版本：1.31.0 为 1 违例、3 通过、1 不确定、4 非法；1.32.0 为 1 违例、10 通过、8 非法。正常同页分批控制在 1.31.0 通过，说明**改变批次边界可能决定是否触发旧故障**，但并非所有重分页都被本工具自动认定合法。空游标前缀若没有后续合格记录，提前停止不构成遗漏，正确判 `PASS`。

`merge`/upsert 对照 `boundary_upsert_set_only` 的目标逻辑 ID 完整，故对本性质判 `PASS`。目标可覆盖重复发射，本工具只判身份完整性，**无法由目标集合反推是否曾重复输出**；对 exactly-once 或重复次数没有结论。正常边界重复读取未被报为漏数。
