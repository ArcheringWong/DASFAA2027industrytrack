# D4 证据审计与偏差

| 结论 | 直接证据 | 解释边界 |
|---|---|---|
| 三项任务先于 D4 维护实施冻结 | `D4_MAINTENANCE_TASKS.md`、`D4_EXPERIMENT_PROTOCOL.md`；`snapshots/base/` | 任务未因 A/B/C 结果替换；冻结协议中的单版本场景上限随后被超出，见下 |
| 两版真实产品与固定依赖 | `evidence/requirements_131.lock`、`requirements_132.lock`、`pip_*` 安装日志；每个原始结果的 `dlt_version` | Python 3.11.4、dlt 1.31.0/1.32.0、DuckDB 1.5.6、Arrow 26.0.0、Hypothesis 6.170.15、pytest 9.0.1；仅合成数据与内存目标 |
| 每任务 A/B/C 的真实结果 | `evidence/base,T1,T2,T3/` 下各版本 `a/b/c_*.json`、`.log`、`manifest.json` | A 为 pytest；B 确定性回放＋另计真实状态机探索；C 为 D3 同一关系；完整源历史、目标行、state、请求批次和错误保留 |
| 维护增量 | `snapshots/base,T1,T2,T3/`、`evidence/diffs/*.patch`、`evidence/summary.json` | 每任务从 base 独立创建；每方案 1 个专有配置文件变化，实际代码快照内容一致；JSON 物理行只是代理 |
| 汇总可复核 | `summarize.py`、`verify_evidence.py`、`evidence/summary_console.txt`、`verification_console.txt` | 文件级断言核对方法间分类一致、核心两故障/修复、非法无执行、源码 hash 和代码快照；不能独立证明产品契约或人类维护成本 |

D4 的 `engine.py` 与 D3 `metamorphic.py` 字节相同；D0–D3 原始文件没有改写。A/B 的完整输入在准备快照时由同一个 D3 合法性函数**派生**，保证对照看到相同源历史；非法案例的拒绝理由也由构造期 D3 验证器给 A/B 配置。这不构成 A/B 自己实现了等价自动合法性证明，且不能据自动生成配置推断开发者书写成本。运行时 A/B 使用共同源身份 oracle 判断单场景完整性，C 运行时另核验前缀中性和原始/变形的预期集合。三方案的资格模型共享假设：稳定完整源、顺序承诺、闭区间、按身份比较。Upsert 重复发射、外部 API 可见性和真实开发团队收益未测。

**开发期修正。** 最初 B 状态机初始化范围仅覆盖前六个案例，故维护新案例无法进入探索；扩展选择后，遇到无可用规则的非法输入，Hypothesis 报 `InvalidDefinition`。修正前代码和失败日志保存为 `evidence/development_pre_fix_*.py`、`development_B_T1_132_invalid_definition.log`。最终 B 加入无条件重新选择规则、12 次真实评估上限并把当前任务新增案例排在探索首位；最终代码复制到四个快照并重跑全部 B。早期 B 运行被覆盖或失败，**不计为独立样本，也不用于比较**。A/C 原始结果来自最终相同的输入快照。上述修正是让 B 达到功能要求，不是为了改善 C 的对照结果；但“初始版本后完全冻结所有代码”未严格实现，故维护成本只能按最终可复核快照评价。

**协议偏差。** 冻结协议写了每版本每方案最多 8 个真实场景；维护快照在 1.32.0 实际有 T1/T2 各 10、T3 有 9 个固定案例，C 的合法案例还需成对执行。这一预算设定与“保留所有原有回归再加新任务”冲突，执行时没有强制。保留全部原始调用，按真实次数收费，不把这批数据包装成严格同预算性能实验。B 状态机探索在最终运行中仅是 4 个生成例的有限样本，部分源于给定新案例，并非盲测搜索；其产生的旧故障变体没有新 Bug 计数。

运行最初在默认沙箱的 dlt 用户目录可写性探测中停滞；堆栈定位于 dlt `is_folder_writable`，未到产品读取。随后以允许的本地隔离环境执行。两次 pip 默认沙箱代理失败、升级权限后公开包索引安装成功，日志均保存。不得把这些环境问题算作连接器执行错误。没有访问生产系统、公司内网、真实数据，也没有向上游提交 Issue/PR。

B 的状态机是有限的连接器回归维护基线：它从已给源历史出发，再做拆批、合批、移除被排除空前缀等操作，并用同一身份 oracle 检查真实执行。它没有从零生成任意多轮提交、恢复和所有合法状态序列；因此不能声称 C 已超过最强可能的 Hypothesis 实现。这个限制使“没有 C 优势”的推断仅适用于这里的合理有限 A/B，不是普遍不可能性证明。
